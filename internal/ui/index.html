VISIONARY

Overview

Everything here is also a command. The line under each control shows the one that does the same thing.

At a glance

Windows Security

Scan

Quick scan covers running programs, autoruns, startup, temp and download folders. Targeted scan checks exactly what you point it at. "Second opinions" sends gray-zone files to Microsoft Defender, reputation and AI.

visionary scan quick --deep

Boot-time scan

Scans drivers, services, autoruns and scheduled tasks at the next startup, as SYSTEM, before anyone logs in. For a scan from outside Windows (rootkits), use Microsoft Defender Offline.
visionary preboot schedule --reboot  ·  visionary windows offline-scan

Threats

Quarantined files are stored encoded so they cannot run. Restore only what you are sure about.

Quarantine

visionary quarantine list  ·  visionary quarantine restore <id> --allow

Recent detections

Explain a file

visionary ai explain <file>

Definitions

Import hash lists (plain, CSV, ClamAV .hdb/.hsb/.cvd), YARA rules or certificate blocklists, or subscribe to a channel that is polled on a schedule.

Import a file

visionary defs import <file>

Sources

Channels

visionary defs channel add <name> <url>  ·  visionary defs channel update

AI

A small local model (under 3B parameters) reviews suspicious files on this PC. A cloud model, reached with your own API key, is asked only when the local one is unsure. Models receive a description of the file, never the file.

Mode
visionary ai mode hybrid

Local model

visionary ai local pull qwen3:1.7b  ·  visionary ai local gguf <file>

Cloud model

visionary ai cloud set-key

Reputation

Only SHA-256 hashes are looked up. Files are never uploaded.
visionary reputation set-key

Behaviour

Visionary learns which programs run here and who starts whom, then flags departures: a new program running from Temp, a chat app spawning PowerShell, a burst of file changes. An anomaly sends the program through every scan layer.

visionary behavior learn --days 3  ·  visionary behavior status

Settings

Profile

Game mode
In game mode scans drop to background priority, and AI, reputation and channel updates wait. Hash, rule and heuristic protection stays on.
visionary profile gamer  ·  visionary gamemode auto

Protection

Exclusions

visionary exclude add <pattern>

Reset

Restores default settings and clears cached scan results. Requires the computer password for . Definitions and quarantine are kept.
visionary settings reset [--all]

Activity

The shared log written by scans, the real-time guard and every settings change.

visionary events -n 50
