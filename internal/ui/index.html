AI Protection Pipeline

At a glance

Windows Security co-existence

Scan

Quick scan inspects running programs, autoruns, startup folders, Temp and Downloads. Targeted scan checks any file or folder. Second opinions escalate gray-zone files and suspicious LOLBin activity to Defender, VirusTotal, local AI and cloud AI.

visionary scan quick --deep

Boot-time & Offline scan

Scans drivers, services, autoruns and scheduled tasks at the next startup as SYSTEM before anyone logs in. Use Microsoft Defender Offline to scan outside Windows for rootkits.
visionary preboot schedule --reboot  ·  visionary windows offline-scan

Threats & AI Analyst

Quarantined files are XOR-encoded and stripped of execute permissions so they cannot run. Use the AI Analyst below to get a plain-English risk briefing on any file or detection.

Quarantine

visionary quarantine list  ·  visionary quarantine restore <id> --allow

AI Protection Engine

Small local models (under 3B parameters) inspect suspicious files and LOLBin process anomalies on this PC. Cloud models (Google Gemini, Anthropic Claude, or OpenAI-compatible) step in when local AI is uncertain or in cloud mode. Models receive structured file telemetry and findings — never the raw executable.

visionary ai mode hybrid  ·  visionary ai sensitivity balanced

Cloud AI Provider

visionary ai cloud provider gemini  ·  visionary ai cloud set-key

Local AI (<3B on-device)

visionary settings set ai.local.keep_alive 0s  ·  visionary ai local unload  ·  visionary ai local pull qwen3:1.7b

GGUF Model Store

GGUF models run through llama.cpp's llama-server. Download from Hugging Face or import your own file. Every model is verified by SHA-256 and its real parameter count is checked against the 3B cap.

visionary ai local hf search <text>  ·  visionary ai local hf get <repo>  ·  visionary ai local models

Hash Reputation (VirusTotal)

Only SHA-256 digests are queried. Files are never uploaded.
visionary reputation set-key

Behaviour & LOLBin Guard

Visionary learns which programs run here and who launches whom, then flags departures: unsigned apps launching from Temp, Office or chat apps spawning PowerShell/mshta/certutil, or rapid file-change bursts. Anomalies escalate directly into AI triage with full command-line lineage.

visionary behavior learn --days 3  ·  visionary behavior status
